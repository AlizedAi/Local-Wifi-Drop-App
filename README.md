# Local Wi-Fi Drop

Lightweight local-network file and message transfer app.

## Platform branches

- `main`: Android
- `windows-10`: Windows 10
- `windows-7`: Windows 7

## Important

Transfers are not encrypted. Do not send sensitive files or messages over public or untrusted networks.
